# Taste of Italy — Corona, Queens

Astro website for Taste of Italy Restaurant & Pizzeria NYC.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Vercel should detect Astro, run `npm run build`, and publish `dist` from the repository root.

The checked-in menu catalog is a validated snapshot of the public Taste of Italy direct-ordering menu. Checkout remains on `https://tasteofitaly.direct-ordering.com/order-now`.
